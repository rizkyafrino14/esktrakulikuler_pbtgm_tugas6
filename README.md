# LKPD 6 PBTGM - Front-End Web

Proyek web interaktif untuk LKPD 6 Pemrograman Berbasis Teks, Grafis, dan Multimedia (PBTGM).

> **Catatan:** Repository ini dibuat untuk memenuhi tugas mata pelajaran PBTGM dengan guru pengajar **Bu Nanin**.

---

## 🛠️ Teknologi yang Digunakan

* **HTML5** - Struktur dasar web
* **Tailwind CSS** - Kerangka kerja CSS untuk desain antarmuka
* **JavaScript** - Logika validasi interaktif

## 💻 Cara Menjalankan Proyek

1. Clone atau unduh repository ini.
2. Buka file `index.html` menggunakan browser web (Google Chrome / Mozilla Firefox).

* atau dengan klik tautan ini https://ekstra_xsata.vercel.app/
